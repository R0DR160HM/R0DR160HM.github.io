Abstract. Hive is a small, compiled, statically-typed language for distributed, highly concurrent systems, built on three ideas: tables are a built-in idea, values behave like values, and the compiler would rather refuse than guess. Out-of-range indexes, unhandled branches and mistyped queries are compile errors, not runtime surprises. Concurrency lives entirely at the call site. This page is written by its author, a software engineer of six years in web applications and distributed systems.
