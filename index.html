Hive, my main project

Hive

A compiled language for distributed systems, in which what would crash does not compile.

Hive is my main project: a small language I designed and built. There is no null, nothing is thrown, and every index is proved in range before the program runs. It compiles to Go and ships as a single native executable. It is young — not yet 1.0 — and its tour covers the whole language in 74 short slides.

Take the tour Source
  • No crashes in production No null, no exceptions, no out-of-range index: what would crash elsewhere does not compile.
  • One process or many machines Services keep their state behind a mailbox, so nothing needs a lock, and calling one across the network looks exactly like calling one locally.
  • Runs everywhere The same code on Windows, Linux, macOS, the browser, a container and Android.

type Claims { user: Str }
proc main(): void {
	if hide(hive.crypto.randomHex(32)) is Result.Ok(key) {
		jwt := hive.crypto.jwtCodec(key)
		token := encode(Claims("ada"), jwt)
		// Checks the signature and the times, then reads the claims.
		if Claims.decode(token, jwt) is Result.Ok(claims) {
			echo claims.user
		}
	}
}

type Note {
	Say   { text: Str }
	Heard { count: Int }
}
// One message at a time: no lock, wherever it runs.
proc inbox(count: mut Int, note: Note): Note {
	count += 1
	return Note.Heard(count)
}
proc main(): void {
	if hive.syslink.listen("10.0.0.1:9100") is Result.Error(e) {
		panic e
	}
	spawn(inbox, 0, #Inbox)
	there := at("10.0.0.2:9100", #Inbox)   // on another machine
	echo there(Note.Say("hi"))
}

Run it on both machines

On the second one, swap the two addresses. A node is identified by where it can be reached, so nothing else about the two processes differs.

Calling the service over there is the same line as calling one here, and messages between two nodes arrive in the order they were sent. “Every connection between two nodes is TLS 1.3, mutually authenticated” (slide 59).
